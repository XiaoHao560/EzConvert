## [v1.5.0] 2026-11-23

### Added
- Added `Custom Command` feature
- Added access to all EzConvert app-private directories through the system document framework

### Fixed
- Fixed a race condition between Worker cancellation requests and asynchronous FFmpeg session creation when cancelling batch tasks
- Fixed an issue where background task progress notifications would occasionally fail to appear
- Fixed an issue where progress bars in task progress notifications would occasionally fail to update correctly
- Fixed an issue where outdated progress updates could overwrite the cleared progress state after task cancellation
- Fixed an issue where Toast messages could not be displayed while the app was running in the background
- Fixed an issue where reselecting files while a task was running could corrupt the current queue state
- Fixed an issue where processing files with the same name within a short period could generate duplicate output paths
- Fixed an issue where the main screen would display outdated task states after returning from a failed background task
- Fixed an issue where output files could not be deleted when cancelling a task after it had completed

### Improved
- Improved app configuration file handling by logging setting changes at DEBUG level
- Improved batch task scheduling and state detection to prevent duplicate foreground service launches
- Improved output filename timestamps to use the device's current time zone
- Improved batch conversion in `Synchronized Parameter Mode` by submitting the entire queue to `WorkManager`
- Improved some UI styles
- Improved file selection persistence when recreating the Activity with files already selected

### Changed
- Updated FFmpegKitNext to v9.0.2
- Changed the title text of task progress notifications
- Changed the theme inheritance of the `Parameter Selection Dialog`
- Changed the `Translucent Toolbar` option to `Transparent Toolbar` under `Custom Background Image`
- Updated some text descriptions
