## [v1.2.0] 2026-09-04

### Added
- Added image format conversion (jpg, png, webp, bmp, tiff, avif)
- Added `File Picker` support for selecting image files (also supports receiving shared image files)

### Fixed
- Fixed the issue where the text color of the update dialog on the `Main Screen` was black in dark mode
- Fixed the issue where video could not be converted to `MKV` format
- Fixed the issue where the output format of `Compress Video Task` and `Trim Video Task` was locked to `MP4`
- Fixed the issue where the `Sync Parameters to All Files` feature was not working

### Improved
- Improved: restore scroll position of scrollable layouts after Activity recreation (when switching theme colors and language settings)

### Changed
- Changed: output different file names based on task type
- Changed: log output content (removed year display)
- Upgraded FFmpegKitNext to v9.0.0

---

- 新增 图片转换格式功能 (jpg, png, webp, bmp, tiff, avif)

- 修复 `参数同步至所有文件` 功能无效的问题

### 优化
