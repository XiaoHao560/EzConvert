## [v1.3.0] 2026-09-26

### Added
- Added `FFmpeg Muxers/FFmpeg Formats` output feature **(Developer feature)**
- Added a setting to modify the file output path
- Added a custom background image setting
- Allowed file managers to **view/read and write** the app's internal private directory

### Fixed
- Fixed the issue where audio files could not be converted to `AAC` format
- Fixed the misalignment between the top text and the back icon in the player component on the `Preview screen`
- Fixed failure during recovery in the `WorkManager recovery mechanism` caused by `FileUtils` being unable to obtain the Uri

### Optimized
- Optimized logic related to the `WorkManager recovery mechanism`

### Changed
- Changed the output folder name from `简转` to `EzConvert` under the `Chinese language` setting

### Code Changes
- Refactored `MainActivity` by separating all UI-unrelated code logic into separate classes
