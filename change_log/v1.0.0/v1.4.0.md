## [v1.4.0] 2026-10-19

### Added
- Added 14 video formats
- Added 15 audio formats
- Added 8 image formats
- Added 56 encoders in total (including video/audio/image)
- Added support for selecting arbitrary media files for processing (limited to media formats supported by ffmpeg)
- Added more notifications (notification when returning to settings parameters / notification when all queue tasks are completed)
- Added translucent toolbar setting
- Added compatibility change notification popup
- Added `Quick Convert` feature (convert without re-encoding)
- Added welcome page shown on first launch
- Added more configurable parameters and custom parameters

### Fixed
- Fixed an issue where queue tasks could not continue after the app was switched to the background when `Sync parameters to all files` was enabled
- Fixed an issue where the preset system could not correctly apply `video/audio encoder` option values

### Changed
- Disabled other related settings options when the `Custom background image` feature is not enabled
- Bumped FFmpegKitNext version to v9.0.1

### Removed
- Removed `heif/heic` formats
- Removed the `-vn` (disable video stream) parameter from audio tasks

### 新增
- 新增 视频格式 14 个
- 新增 音频格式 15 个
- 新增 图片格式 8 个
- 新增 编码器 共 56 个 (其中包括 视频/音频/图片)

- 新增 半透明 toolbar 设置

- 新增 更多可配置参数 与 自定义参数

### 修复
- 修复 在启用 `参数同步至所有文件` 后，将应用切换至后台状态时无法继续推进队列任务的问题
- 修复 预设系统无法正确应用 `视频/音频编码器` 选项值的问题

### 变更
- 在未开启 `自定义背景图片` 功能时，禁用其他相关设置选项
- 提升 FFmpegKitNext 版本至 v9.0.1

### 移除
- 移除 `heif/heic` 格式
- 移除 音频任务中的 `-vn` (禁用视频流) 参数
